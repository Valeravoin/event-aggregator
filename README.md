# EventAggregator — бэкенд‑агрегатор событий

Агрегатор событий на стеке **FastAPI + SQLAlchemy + PostgreSQL**. Проект собирает события из разных источников, хранит их в единой базе, обеспечивает идемпотентную синхронизацию и отдаёт через REST API с пагинацией.

## 🚀 Быстрый старт

### 1. Требования
- Python 3.10+
- PostgreSQL (база `event_aggregator` должна быть создана)
- Локальная установка зависимостей (через `venv`)

### 🧠 Архитектура и ключевые решения
Идемпотентная синхронизация: повторные запуски не создают дубликатов — используется upsert по UUID.
Фоновая синхронизация: реализована через APScheduler (запуск по расписанию).
Пагинация и подсчёт: отдельные запросы для COUNT(*) и выборки данных — это предотвращает ошибки SQLAlchemy и лишние данные в ответе.
Безопасные сессии БД: SessionLocal и контекст yield гарантируют закрытие сессии даже при ошибках.
UUID как идентификаторы: все сущности используют UUID, что удобно для распределённых систем.
Вынос секретов: DATABASE_URL вынесен в переменные окружения.
